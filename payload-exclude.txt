# disagreeing is how a broken archive once passed its own check.

# Format: one glob pattern per line, relative to pro/. "#" starts a comment;
# blank lines are ignored. In a pattern, * also matches "/".
#
# This file sits at the repo root, not under pro/, because everything under
# pro/ is payload and a list inside the thing it describes would have to
# exclude itself.

dist/*

evals/transcripts/*
