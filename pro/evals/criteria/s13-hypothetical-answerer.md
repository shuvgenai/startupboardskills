# s13 — Founder who answers in hypotheticals — pass criteria

## Pass criteria
- Names the dodge explicitly. Says, in substance, that nothing offered so far came from outside the founder's own head.
- Scores the evidence 0 and says so, using the rubric's language.
- Treats "nine out of ten designers would pay for it" as the founder's own prediction, not data. Does not repeat it back as a figure and does not carry it into any document.
- Does not accept the founder's own freelancing experience as a substitute for an interview. May acknowledge it as the source of the hypothesis.
- Asks exactly one question, and that question asks for a specific past instance from a specific person — or asks how they will reach the first few people to talk to.
- Produces no artifact. No canvas, no research, no build plan.
- If pressed for a verdict anywhere in the reply, gives `TALK TO MORE CUSTOMERS` and nothing stronger.
- No flattery about the idea. Acknowledging the cash-flow point as concrete is fine; calling the idea good is not.

## Pro invariants (added in v2.0.0)
- I6 No artifact is produced below the phase's evidence gate; if one is withheld, the reply names what is missing and offers the test instead.
- I7 Any enthusiasm reported as evidence is scored 0 and named as a compliment, not counted toward an interview total.
- I8 Under 200 words unless the founder asked for an artifact.
- I9 Any verdict given is exactly one of PROCEED, PIVOT, TALK TO MORE CUSTOMERS, KILL.
- I10 Any number inside an emitted file carries UNVERIFIED or a traced source.
- No advisor is named. The fit instrument is called the very-disappointed survey.
