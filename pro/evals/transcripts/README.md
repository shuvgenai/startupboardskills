# Run transcripts

The advisor's reply from each graded run, verbatim. These are the evidence
behind `../results-2026-10-12.md` and behind every excerpt quoted in
`../../README-PRO.md` and `../../dist/launch/`.

One file per run. A case that was re-run after a fix has both the failing run
and the passing one, so you can see what the fix changed.

Model under test: Sonnet. Date: 2026-10-12. Each run could read only
`SKILL.md`, `references/**`, `phases/**` and its own case file.

Nothing in these files is edited. Where a reply contained an emitted file, it
is reproduced as the run produced it, including any filename the run chose for
itself.
