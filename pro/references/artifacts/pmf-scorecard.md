# Product-market fit scorecard

**Earned at:** Phase 09, after the signals are measured.

## Template

```
# Fit scorecard: <product> — <date>
> <gap stamp, only if an earlier stage was not passed>
Active user: <definition> · Natural rhythm: <daily | weekly | monthly>

| Signal | Value | Responses | How it was measured | verified? | Result |
|---|---|---|---|---|---|
| Very disappointed, overall | UNVERIFIED | UNVERIFIED | <source> | no | <met / not met / directional> |
| Very disappointed, <segment> | UNVERIFIED | UNVERIFIED | <source> | no | <...> |
| Retention, <cohort> | UNVERIFIED | — | <source> | no | <levels off / still sliding> |
| Pull | UNVERIFIED | — | <source> | no | <present / growing / absent> |

**Verdict:** <Not yet | In one segment — <segment> | Yes>
**Why:** <2-3 sentences using only the numbers above>
**One next action:** <one action>
**Not measured yet:** <signal — kit handed over>   (omit if everything was measured)
```

## Rules

- Every value is either a measured figure with its source and as-of date, or
  `UNVERIFIED`. There is no third option and no estimating.
- The bar figures are rules of thumb and are written as such wherever they
  appear.
- **Never Yes while a signal is unmeasured.** Say the rest looks promising,
  name the missing one, hand over the kit.
- A segment above the bar on fewer than about 30 responses can still earn
  *In one segment*, labelled directional.
- If a previous scorecard exists, add one line stating the trend between them.
- On *Yes*, mark Market as passed in `references/state-file.md`. On *In one
  segment*, mark it passed for that segment only, and keep every later phase
  inside it.
