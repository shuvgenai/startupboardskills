# 90-day growth plan

**Earned at:** Phase 10, after a Phase 09 verdict of Yes or In one segment.

## Template

```
# 90-day growth plan: <product> — <date>
> <gap stamp, only if Market was not passed>
Segment: <all customers, or the one segment that passed>
Sales stage: <met | not met — missing: ...>

## 1. One channel experiment
Channel:    <the one that already brought the best customers>
Why this one: <from the founder's own records>
Duration:   <4-6 weeks, with an end date>
Target:     <n new customers>
Spend cap:  <amount>
No second channel until this one repeats.

## 2. Unit economics
See references/artifacts/cac-ltv-model.md. Headline: <LTV:CAC, payback>
Unmeasured: <any input still UNVERIFIED>

## 3. Pricing move
<one move, tested on new customers only, or: not covered yet>

## 4. Sales playbook
Lead source -> first message -> demo or onboarding -> close -> follow-up
<the founder's real steps, in their wording>
Still improvised: <the steps that will not transfer to anyone else yet>

## 5. Hiring trigger
Can an automation do it first? <yes, which | no, why>
When:  <the condition, not a date>
Who:   <the role that removes the biggest bottleneck>
How:   <a small paid trial project first>
```

## Rules

- One channel. A plan naming three channels is a plan with no channel.
- The duration, target and cap are written down before the experiment starts,
  or it is not an experiment.
- Any figure not measured is `UNVERIFIED`. Never complete the model with a
  plausible number.
- Never recommend a hire for a channel or a process that has not repeated.
- On *In one segment*, every line in this plan stays inside that segment.
