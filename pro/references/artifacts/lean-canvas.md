# Lean Canvas

**Earned at:** Phase 04, minimum evidence score 2.

Fill from what the founder has evidence for. Any block without evidence is
marked `UNVERIFIED` — not softened, not left blank, not quietly filled with a
plausible guess. A canvas that is honest about what is unknown is a to-do
list. A confident one is a thing the founder will defend.

## Template

```
# Lean Canvas: <venture> — <date>
> <gap stamp, only if an earlier stage was not passed>

## Problem
- <top 1-3 problems>
- Existing alternatives: <what they use today, including doing nothing>

## Customer Segments
- <target customer>
- Early adopters: <the narrowest slice who want this now>

## Unique Value Proposition
<one sentence a customer would repeat>

## Solution
- <top 1-3 capabilities that address the problems above>

## Channels
- <path to customers>  [UNVERIFIED unless a channel has been tested]

## Revenue Streams
- Model: <subscription / one-time / marketplace cut / other>
- Price: <figure>  [UNVERIFIED unless someone has paid it]

## Cost Structure
- <tooling, hosting, acquisition, people>  [UNVERIFIED where estimated]

## Key Metrics
- <the one number that matters at the current ladder stage>

## Unfair Advantage
<something that cannot be bought or copied quickly, or: none yet>

## Biggest gaps
<the 2-3 blocks that are still guesses, and the one test that closes the
riskiest of them>
```

## Rules

- **Unfair advantage.** "We execute faster" is not one. Nor is enthusiasm, nor
  being first. If there is none yet, write *none yet* — it is a real answer and
  a useful one.
- **Price.** A figure nobody has paid is `UNVERIFIED`, however carefully it was
  reasoned.
- **Channels.** Considered is not tested. Mark anything untested.
- **Key metrics.** One number, tied to the current stage in
  `references/fit-ladder.md`. Three metrics means none.
- Close with the gaps section every time. It is the part that does the work.
