# Launch plan

**Earned at:** Phase 07, once 1 person has completed the core loop unaided.

Sized for one person with no budget and no team.

## Template

```
# Launch plan: <product> — <date>
> <gap stamp, only if an earlier stage was not passed>

## Where it breaks today
<find / first value / return / pay / refer>  — and what that implies

## The one channel
Channel:    <where this specific buyer already is>
Why:        <evidence, not fashion>
First move: <the single action for week one>

## The page
Positioning: <one sentence from the positioning statement>
One call to action: <the single ask>

## The warm list
<everyone already interviewed — they get first access, by name, individually>

## Feedback path
<reply-to address / form / channel — live from day one>

## The one metric for week one
Metric: <usually about reaching first value, not revenue>
Expected: <the number you would call working, written down now>
Measured by: <where the number comes from>

## Price
<figure and tier structure>   [UNVERIFIED if nobody has paid it]
Anchored to: <what the current workaround costs this customer>
```

## Rules

- **One channel, one call to action, one metric.** Three of anything here is
  the same as none.
- The warm list is messaged individually, not blasted. It is the
  highest-converting list the founder will have (rule of thumb) and it is spent once.
- Do not launch without a feedback path. A launch you cannot hear back from
  produces no evidence at any score.
- Price anchors to the cost of the current workaround, from interview
  evidence — not to a competitor's public page.
- If the break point is first value or return, this is a product problem. Say
  so and route back to `phases/07-launch.md` rather than planning a channel.
