# Experiment card

**Earned at:** Phase 01, any evidence score. This is the instrument that
produces evidence, so it is always available.

One card per assumption. The pass number is decided **before** the test runs.

## Template

```
# Experiment: <short name> — <date>
Assumption id: <A1 from the ledger>

## The assumption
<one sentence, stated so it could be wrong>

## If-then
If <action>, then <measurable result>.

## The test
Method:     <what you will actually do>
Who:        <which people, and how you reach them — not your existing network>
Duration:   <a date it ends>
Cost cap:   <money and hours>

## Pass number (decided before running)
<the threshold that counts as the assumption surviving>   [decided <date>]

## Result
Ran:        <date, or not yet>
Outcome:    <what happened, in numbers>   [UNVERIFIED until measured]
Score:      <0-3 against references/evidence-rubric.md>
Verdict:    <assumption survived / did not survive / inconclusive, and why>
```

## Rules

- **The pass number is dated.** A threshold written after the result is not a
  threshold, and the card is worthless without it. This is the single most
  common way a test produces nothing.
- **A test that could not fail produces no evidence** at any score. If no
  outcome would change the founder's mind, it is not an experiment.
- **People you already know do not count** toward a test about the market.
- One assumption per card. A card testing three things tests none.
- The result goes into `## Assumption ledger` and `## Evidence log` in
  `references/state-file.md`, whichever way it went. A negative result is the
  cheapest thing the founder will ever buy.
